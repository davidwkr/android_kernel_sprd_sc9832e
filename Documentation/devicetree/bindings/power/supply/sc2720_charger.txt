Spreadtrum SC2720/SC2721 PMIC battery charger binding

Required properties:
 - compatible: Should be "sprd,sc2720-charger" or "sprd,sc2721-charger".
 - reg: Address offset of charger register (CHGR_CTRL0; CHGR_CTRL1 follows at
   +0x4). For the SC2721 this is 0xec0.
 - phys: Contains a phandle to the USB phy.
 - nvmem-cells, nvmem-cell-names: the CCCV calibration. "cccv_calib" is
   required for both chips (6 bits). The SC2721 additionally requires
   "cccv_calib_valid" (efuse valid flag, bit 0 of efuse block 0); when the flag
   is clear the calibration defaults to 0x20. Probe fails if a required cell
   is missing.

Optional Properties:
- monitored-battery: phandle of battery characteristics devicetree node.
  The charger uses the following battery properties:
- charge-term-current-microamp: current for charge termination phase.
- constant-charge-voltage-max-microvolt: maximum constant input voltage.
  See Documentation/devicetree/bindings/power/supply/battery.txt

SC2721 notes:
- The charge current is clamped to 300..1300 mA in 50 mA steps and the
  constant charge voltage to 4400 mV; the input over voltage protection is
  not programmed.
- The module parameter sc2720_charger.cv_override_mv (4000..4400 mV, 0 = off)
  caps the constant charge voltage of the SC2721 charger. See
  devices/SC2721_CHARGER_MAP.md.

Example:

	bat: battery {
		compatible = "simple-battery";
		charge-term-current-microamp = <120000>;
		constant-charge-voltage-max-microvolt = <4350000>;
		......
	};

	sc2720_pmic: pmic@0 {
		compatible = "sprd,sc2720";
		reg = <0>;
		spi-max-frequency = <26000000>;
		interrupts = <GIC_SPI 31 IRQ_TYPE_LEVEL_HIGH>;
		interrupt-controller;
		#interrupt-cells = <2>;
		#address-cells = <1>;
		#size-cells = <0>;

		charger@0 {
			compatible = "sprd,sc2720-charger";
			reg = <0x0>;
			phys = <&ssphy>;
			monitored-battery = <&bat>;
		};
	};
