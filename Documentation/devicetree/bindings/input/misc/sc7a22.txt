Sensortek SC7A22/SC7A20 three-axis accelerometer

Required properties:
- compatible: must be "sprd,sc7a22"
- reg: I2C address of the sensor

Optional properties:
- layout: mounting orientation from 0 through 7. Defaults to 0. Written to the
  orientation register as layout | 0x70.
- angle: hand-up angle, written to the hand-up angle register. Defaults to 10.
  The K18 stock tree uses 0x75.
- irq-gpio: GPIO of the chip's interrupt line (level high). Without it the
  hand-raise key is not available.
- hand-up-ctrl: value for the hand-up control register (0x08) of the 0x13
  part. Defaults to 0x11 (the DM63 and MT107 stock firmware); the K18 and
  DW100U stock firmware writes 0x21.

Example:

	sc7a22_acc@18 {
		compatible = "sprd,sc7a22";
		reg = <0x18>;
		layout = <0>;
		angle = <0x75>;
		irq-gpio = <&gpio 93 0>;
	};
